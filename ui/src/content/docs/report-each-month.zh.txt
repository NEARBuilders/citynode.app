# 每月提交报告

社区所有者和组织者每月在 City Node 提交一份简短报告，并在每场活动结束后为其提交一份活动报告。

## 从这里开始

打开[您的报告](/report)。如果 City Node 要求，请先登录；如果您负责多个社区，请选择一个。页面会显示本月报告、仍可编辑的上月报告，以及所有已结束但仍需报告的活动。每一项都只需点击一次。

只有所有者和拥有“活动”权限团队的成员可以提交报告。如果页面提示报告由所有者和组织者提交，请让社区所有者把您加入该团队。

## 月度报告包含什么

City Node 会为您自动填写本月数据：

- **已举办活动：**当月开始且已结束的已发布活动。
- **签到：**当月在您的活动中通过您的二维码签到的人数。
- **加入次数**和**新成员：**当月通过您的二维码加入社区的人数，以及其中首次使用 City Node 的人数。

提交时，这些数据会随报告一起保存，之后不会再变化。

然后在一个开放的文本框里写下发生了什么，长短随意。没有固定问题。可以写：

- 亮点，以及大家做出了什么、学到了什么
- 提供帮助的人、合作伙伴和场地
- 哪些做法效果不好，下次准备怎么做
- 您需要平台团队提供的支持

## 截止时间

月度报告从 2026 年 11 月开始。每个月的报告请在下个月结束前提交。从每月最后一周开始，City Node 会在主页提醒您。在下个月结束前，您可以重新打开并修改报告；之后报告变为只读。

## 活动报告

每场已结束的活动都有自己的报告，包含几个固定问题。可从[您的报告](/report)或**我的社区**打开。保存活动报告或月度报告后，City Node 会带您回到报告页面，下一份报告只需点击一次。

## 谁能看到

您、社区的其他所有者和组织者，以及 City Node 平台团队。其他人无法查看。

平台团队会阅读每份报告并标记为**已审阅**，您可以在[您的报告](/report)和报告本身看到。他们不会通过 City Node 发回评论。如果您在审阅后修改了报告，报告会重新交给他们阅读。
